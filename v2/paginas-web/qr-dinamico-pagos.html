QR DINÁMICO · PAGOS WEB

Página web con QR dinámico y pagos automáticos

La integración parte desde +USD 150 y depende de que el banco o pasarela del negocio ofrezca una API compatible para generar cobros y confirmar pagos de forma segura.

Cada cliente usa su propia cuenta bancaria, pasarela y credenciales.

Cómo funciona

  1. La web crea un pedido con un monto autoritativo en el servidor.
  2. El backend solicita al banco o pasarela un QR o cobro asociado al pedido.
  3. El cliente paga con el medio habilitado.
  4. El backend confirma el pago mediante API, callback o webhook del proveedor.
  5. La web actualiza el pedido sin depender de un botón del navegador para marcarlo como pagado.

Qué debe entregar el cliente

Si el banco ofrece API para comercios, se necesitan las credenciales de integración que el propio banco entregue: identificador de comercio, llaves, ambiente de pruebas/producción y datos de callback o webhook, según corresponda. Si se utiliza una pasarela como Libélula, la afiliación y credenciales pertenecen al negocio del cliente.

Las claves privadas nunca se publican en el frontend.

Si tu banco no tiene API

Podemos evaluar una pasarela compatible o dejar un QR con verificación manual. El precio final depende de la integración real, pruebas y requisitos del proveedor.
